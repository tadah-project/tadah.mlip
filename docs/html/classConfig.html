Detailed Description

A dictionary for key - value pairs.

This dictionary object must be used in the workflow to configure other objects in the training process.

A Config object stores information such as:

  • cutoff distances
  • descriptor parameters
  • paths to training database files
  • and many more...

Every object using a Config class specifies a list of required and optional KEY - VALUE pairs.

The config keys and values are case insensitive.

List of supported key-value pairs:

  • DBFILE <string> str

    Absolute or relative path to the training database file. The relative path is to the script working directory. More than one can be specified to include several datasets.

    e.g. DBFILE /home/user12/project/db.dat

  • INIT2B <string> true/false

    Whether to calculate two-body type (D2_Base) descriptor.

    e.g. INIT2B true

  • INIT3B <string> true/false

    Whether to calculate three-body type (D3_Base) descriptor.

    e.g. INIT3B true

  • INITMB <string> true/false

    Whether to calculate many-body type (DM_Base) descriptor.

    e.g. INITMB true

  • TYPE2B <string> name

    Type of a two-body descriptor to be used. Any type which inherits from D2_Base is fine here.

    e.g. TYPE2B D2_LJ

  • TYPE3B <string> name

    Type of a three-body descriptor to be used. Any type which inherits from D3_Base is fine here.

    e.g. TYPE3B D3_LJ

  • TYPEMB <string> name

    Type of a many-body descriptor to be used. Any type which inherits from DM_Base is fine here.

    e.g. TYPEMB DM_EAM

  • RCTYPE2B <string> name

    Cutoff type to be used with two-body descriptor. Any type which inherits from CutoffBase is fine here.

    e.g. RCTYPE2B BPCutoff

  • RCTYPE3B <string> name

    Cutoff type to be used with three-body descriptor. Any type which inherits from CutoffBase is fine here.

    e.g. RCTYPE3B BPCutoff

  • RCTYPEMB <string> name

    Cutoff type to be used with many-body descriptor. Any type which inherits from CutoffBase is fine here.

    e.g. RCTYPEMB BPCutoff

  • RCUT2B <double> N

    Cutoff distance used by the two-body type descriptor.

    e.g. RCUT2B 6.7

  • RCUT3B <double> N

    Cutoff distance used by the three-body type descriptor.

    e.g. RCUT3B 5.5

  • RCUTMB <double> N

    Cutoff distance used by the many-body type descriptor.

    e.g. RCUTMB 8.5

  • AGRID3B<int> N

    AGRIDMB<int> N

    Size of angular grid for three- and some many-body types.

  • CGRID2B CGRID3B CGRIDMB

    A number of position parameters of the radial basis functions for a two-, three- and many-body descriptor, e.g. position of a Gaussian function. The parameter list can be provided or generated automatically. Note that not all descriptors use this parameter, e.g. D2_LJ has fixed grid.

    • CGRID2B <double> N1 N2 N3 ...

      Provide a list of position parameters. Note that N1 value can be negative in principle but NOT NEGATIVE INTEGER (e.g. -1 or -1.000 won't work, but -1.0001 is fine).

      e.g. CGRID2B 1.14 3.45 4.55 6.73

    • CGRID2B <int> -A N <double> min max

      Generate a series of N points between min and max with -A algorithm. min>=0 and max>=0. Available algorithms: '-1' evenly spaced points between min and max. '-2' as above but numbers are evenly spaced on a log scale.

      e.g. CGRID2B -1 6 0.5 7.4

  • SGRID2B SGRID3B SGRIDMB

    A number of shape parameters of the radial basis functions for a two-, three- and many-body descriptor, e.g. width of a Gaussian function. The parameter list can be provided or generated automatically.

    • SGRID2B <double> N1 N2 N3 ...

      Provide a set of shape parameters. All numbers must be positive. e.g. SGRID2B 0.12 0.33 1.0 5.1

    • SGRID2B <int> -A N <double> min max

      Generate a series of N points between min and max with -A algorithm. min>=0 and max>=0. Available algorithms: '-1' evenly spaced points between min and max. '-2' as above but numbers are evenly spaced on a log scale.

      e.g. SGRID2B -1 6 0.5 7.4

  • MPARAMS <double> N1 N2 N3 ...

    List of parameters used by some models. See model description for more details. Note that many models do not require this parameter at all.

    e.g. MPARAMS 0.1

  • FORCE <string> true/false

    Whether to calculate FD and use forces in a training,

    e.g. FORCE true

  • STRESS <string> true/false

    Whether to calculate SD and use cell stresses in a training,

    e.g. STRESS false

  • SBASIS <int> N

    The number of basis functions to use with when constructing DesignMatrix.

    e.g. SBASIS 10

  • NORM <string> true/false

    Set true to normalise descriptors.

    e.g. NORM true

  • LAMBDA <double> N

    Default: LAMBDA -1

    Regularisation parameter for BLR and KRR.

    • LAMBDA == 0 -> use OLS
    • LAMBDA > 0 -> manually set to given value
    • LAMBDA < 0 -> use evidence-approximation to estimate \(\lambda\)

    e.g. LAMBDA 1e-5

  • ALPHA <double> N

    Weight precision hyper-parameter. Starting guess used in evidence approximation algorithm. Default: ALPHA 1.0

    e.g. ALPHA 0.23

  • BETA <double> N

    Noise precision hyper-parameter. Starting guess used in evidence approximation algorithm. Default: BETA 1.0

    e.g. BETA 0.0001

  • SETFL <string> path/to/setfl/file

    Path to setfl file with eam potentiaal

    e.g. SETFL Ta1_Ravelo_2013.eam.alloy

  • BIAS <string> true/false

    Controls whether to append 1 to every descriptor. Increases DSIZE by 1.

    e.g. BIAS true

  • VERBOSE <int> N

    Provides detailed output for diagnostic purposes for N>0. Default: VERBOSE 1

    e.g. VERBOSE 0

  • EWEIGHT <double> N

    Global energy scalling factor for all configurations used in training. Note that energies are always scalled by 1/number of atoms. Individual scalling factors for every configuration can be set in a dataset file.

    The combined scalling factor is: EWEIGHT*(configuration eweight)/(number of atoms)

    Default: EWEIGHT 1.0

    e.g. EWEIGHT 0.95

  • FWEIGHT <double> N

    Global force scalling factor for all configurations used in training. Note that each force component is always scalled by 1/(number of atoms)/3. Individual scalling factors for every configuration can be set in a dataset file.

    The combined scalling factor is: FWEIGHT*(configuration fweight)/(number of atoms)/3

    Default: FWEIGHT 1.0

    e.g. FWEIGHT 0.1

  • SWEIGHT <double> N

    Global stress scalling factor for all configurations used in training. Note that each stress component is always scalled by 1/6. Individual scalling factors for every configuration can be set in a dataset file.

    The combined scalling factor is: SWEIGHT*(configuration Sweight)/6

    Default: SWEIGHT 1.0

    e.g. SWEIGHT 0.05

  • WEIGHTS <double> N1 N2 N3 ...

    WEIGHTS are machine learned coefficiens. This key is used during prediction for the lammps interface.

    e.g. WEIGHTS 0.12 1.2 0.3

  • SIGMA <int> N <double> N1 N2 N3 ...

    Sigma matrix for Bayesian Linear Regression. Sigma is NxN matrix. Stored in col by col order.

    1.2 2.3 2.2 3.3

    e.g. Sigma 2 1.2 2.2 2.3 3.3

  • MODEL <string> <Model type> <Basis function or kernel type>

    MODEL Any class which inherits from Model class.

    e.g. MODEL BLR Linear e.g. MODEL BLR Polynomial2 e.g. MODEL KRR LinearKernel

  • NSTDEV <double> N1 N2 N3 ...

    NSTDEV Normaliser standard deviations.

  • NMEAN <double> N1 N2 N3 ...

    NMEAN Normaliser means.

  • BASIS <double> N1 N2 N3 ...

    Basis vectors used by non-linear KRR model.

List of internally used keys:

Warning
INTERNAL_KEY
Do not try to set internal keys. Corresponding values are calculated by the library when required. User can access internal key-value pairs as usually.

  • <INTERNAL_KEY> DSIZE <int>

    Total dimension of a descriptor. DSIZE = SIZE2B + SIZE3B + SIZEMB. Set by a Calculator.

  • <INTERNAL_KEY> SIZE2B <int>

    Dimension of a two-body descriptor. Set by a Calculator.

  • <INTERNAL_KEY> SIZE3B <int>

    Dimension of a three-body descriptor. Set by a Calculator.

  • <INTERNAL_KEY> SIZEMB <int>

    Dimension of a many-body descriptor. Set by a Calculator.

  • ATOMS <string> A1 A2 ...

    List of atom types. Read from training database files. e.g. ATOMS Ti Nb

  • RCUTMAX <string> A1 A2 ...

    Maximum cutoff distance, max(RCUT2B,RCUT3B,RCUTMB)

  • ESTDEV <double> N

    Energy standard deviation (energy/atom).

  • FSTDEV <double> N

    Force standard deviation (energy/distance).

  • SSTDEV <double> xx xy xz yy yz zz

    Stress standard deviations (energy units).
