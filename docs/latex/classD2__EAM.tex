\doxysubsection{Detailed Description}
Pair-\/wise part for the Embedded \mbox{\hyperlink{structAtom}{Atom}} Method descriptor. 

\[ V_i = \frac{1}{2} \sum_{j \neq i} \psi(r_{ij}) \]

This descriptor will load tabulated values for the two-\/body potential $ \phi $ from the provided \mbox{\hyperlink{classConfig_SETFL}{S\+E\+T\+FL}} file.

This descriptor is usually used together with the many-\/body descriptor \mbox{\hyperlink{classDM__EAM}{D\+M\+\_\+\+E\+AM}} although this is not required and user can mix it with any other descriptors or use it on its own.

This descriptor will enforce cutoff distance as specified in a \mbox{\hyperlink{classConfig_SETFL}{S\+E\+T\+FL}} file. Set \mbox{\hyperlink{classConfig_RCUT2B}{R\+C\+U\+T2B}} to the same value to suppress the warning message.

Required \mbox{\hyperlink{classConfig}{Config}} keys\+: \mbox{\hyperlink{classConfig_INIT2B}{I\+N\+I\+T2B}} \mbox{\hyperlink{classConfig_SETFL}{S\+E\+T\+FL}}
