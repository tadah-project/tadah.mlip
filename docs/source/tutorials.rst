.. _tutorials:

Tutorials
=========

This page points to the step-by-step material of the site. The
:doc:`quickstart` trains a potential, predicts with it and runs it in
LAMMPS, and the :ref:`cli_examples` collect worked examples of the
``tadah`` command. The :ref:`nfp_quickstart` of the Nested Fitting chapter
shows the shortest run of nested fitting. Its :ref:`nfp_tutorial` builds a
potential for tantalum from DFT data, in units that run in order: from a
first search of one setting with ``tadah hpo`` to properties from LAMMPS,
global searches, annealing and more data.
