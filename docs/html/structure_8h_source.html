109  /* Return corresponding ii index of i-j (jj) atom interaction.
110  *
111  * The ii index is used with nearest neighour lists.
112  * i,j are atom global indices; ii,jj are neighbour lists indices.
113  *
114  * This method is required to fully specify interacton of two atoms
115  * when predicting force on the i-th atom. In particular in the case when
116  * atom i-j interaction is specified more than once. e.g. one i-j interaction
117  * in the main box and another one coming from the periodic shift.
118  * The critical condition for this to happen for the square box is:
119  * rcut > box length / 2.
120  *
121  * e.g.
122  * To get a force on atom i. We loop over nn of i -> gives jj index.
123  * For many-body potentials we also need to know the density for atom at jj,
124  * hence we need j index. This is stored by:
125  *
126  * j=near_neigh_idx[a][jj]
127  *
128  * Moreover we need to know derivatives (descriptor derivatives wrt to rij)
129  * at both i and j atoms. However if jj atom is outside of the main box
130  * we do not calculate derivative for this atom but we can use derivative
131  * for the j-ii interaction. Hence we need to find ii index here... phew...
132  *
133  * ii = get_nn_iindex(i,j,jj)
134  */
135  const size_t get_nn_iindex(const size_t i, const size_t j, const size_t jj) const;
