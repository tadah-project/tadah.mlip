\doxysubsection{Detailed Description}
Embedded \mbox{\hyperlink{structAtom}{Atom}} Descriptor

\[ V_i^{L,\eta,r_s} = \sum_{l_x,l_y,l_z}^{l_x+l_y+l_z=L} \frac{L!}{l_x!l_y!l_z!} \Big( \rho_i^{\eta,r_s,l_x,l_y,l_z} \Big)^2 \]

where density $ \rho $ is calculated using Gaussian Type Orbitals\+: \[ \rho_i^{\eta,r_s,l_x,l_y,l_z} = \sum_{j \neq i} x_{ij}^{l_x}y_{ij}^{l_y}z_{ij}^{l_z} \exp{\Big(-\eta(r_{ij}-r_s)^2\Big)}f_c(r_{ij}) \]

\mbox{\hyperlink{classConfig_CGRIDMB}{C\+G\+R\+I\+D\+MB}} parameters control position $ r_s $ of the gaussian basis function.

\mbox{\hyperlink{classConfig_SGRIDMB}{S\+G\+R\+I\+D\+MB}} parameters control width $ \eta $ of the gaussian basis function.

\mbox{\hyperlink{classConfig_AGRIDMB}{A\+G\+R\+I\+D\+MB}} parameter specify maximum value for the angular momentum $L_{max}$.

e.\+g. $L_{max}=2$ will calculate descriptors with $ L=0,1,2 $ (s,p,d orbitals).

More information about this descriptor\+:

Zhang, Y., Hu, C.,Jiang, B. (2019). Embedded atom neural network potentials\+: efficient and accurate machine learning with a physically inspired representation. {\itshape Journal of Physical Chemistry Letters}, {\itshape 10}(17), 4962–4967. \href{https://doi.org/10.1021/acs.jpclett.9b02037}{\texttt{ https\+://doi.\+org/10.\+1021/acs.\+jpclett.\+9b02037}}
