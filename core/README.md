# core

The foundation library of Tadah!: the configuration store (`Context`), the
registry of configuration keys and command-line options
(`blueprint/blueprint_tadah.toml`), the periodic table, and the numerical
and logging helpers the other modules share.

`core` is a module of the [Tadah! repository](../README.md) and is built
with it. The [installation guide](https://tadah.readthedocs.io/latest/installation.html) describes the build.
