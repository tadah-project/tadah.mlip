# models

The model components of Tadah!: descriptors, cutoff functions, kernels, and
the regressors `M_KRR` and `M_BLR` with their solvers. The documentation
describes them for a user: [descriptors](https://tadah.readthedocs.io/v1-dev/descriptors.html),
[cutoffs](https://tadah.readthedocs.io/v1-dev/cutoffs.html) and [regressors](https://tadah.readthedocs.io/v1-dev/regressors.html).

`models` is a module of the [Tadah! repository](../README.md) and is built
with it, on top of [`core`](../core). The
[installation guide](https://tadah.readthedocs.io/v1-dev/installation.html) describes the build.
