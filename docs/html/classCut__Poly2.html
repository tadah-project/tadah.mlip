Detailed Description

Polynomial-2 cutoff function.

\[ f_c(r) = \begin{equation} \begin{cases} 1 & \text{if } r \leq (r_c-1)\\ r^3(r(15-6r)-10)+1 & \text{if } (r_c-1) < r \leq r_c\\ 0 & \text{otherwise}\\ \end{cases} \end{equation} \]

Singraber, A., Rg Behler, J., Dellago, C. (2019). Library-Based LAMMPS Implementation of High-Dimensional Neural Network Potentials. https://doi.org/10.1021/acs.jctc.8b00770
