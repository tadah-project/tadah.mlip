API Quick Start
===============

This page points to the shortest way into the C++ library. It needs the installed libraries and their include and link flags (:ref:`compiling_and_linking`).

:ref:`Example 1 <ex1>` trains a model from a training configuration and predicts with it. :ref:`Example 2 <ex2>` predicts with an existing trained model. Both examples list their source files in full.

The classes and functions used in the examples are described in the API Reference.
