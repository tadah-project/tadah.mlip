This constructor is equivalent to the main constructor above.

The difference is technical in nature. Here we use O\+OP with generic programming to call virtual functions to calculate descriptors -\/ this incurs small efficiency penalty but makes selecting of descriptors somewhat easier at runtime.

In contrast, the main constructor above is purely generic.

The rule of thumb is\+: Use the main contructor unless it\textquotesingle{}s a pain.
