\doxysubsection{Detailed Description}
Container for a structure descriptors. 

Contains\+:
\begin{DoxyItemize}
\item Atomic Energy Descriptors
\item Force Descriptors (Optional)
\item Stress Descriptors (Optional)
\end{DoxyItemize}

To fully initialise this object it needs to know\+:
\begin{DoxyItemize}
\item number of atoms in a structure (from \mbox{\hyperlink{structStructure}{Structure}})
\item number of nn for every atom (from \mbox{\hyperlink{structStructure}{Structure}})
\item dimension of the descriptor vector (\mbox{\hyperlink{classConfig}{Config}})
\item whether force and stress is being calculated (from \mbox{\hyperlink{classConfig}{Config}})

\begin{DoxyNote}{Note}
Required \mbox{\hyperlink{classConfig}{Config}} keys\+: \mbox{\hyperlink{classConfig_FORCE}{F\+O\+R\+CE}} \mbox{\hyperlink{classConfig_STRESS}{S\+T\+R\+E\+SS}}. \mbox{\hyperlink{classConfig_INTERNAL_KEY}{I\+N\+T\+E\+R\+N\+A\+L\+\_\+\+K\+EY}} \mbox{\hyperlink{classConfig_DSIZE}{D\+S\+I\+ZE}}. 
\end{DoxyNote}

\end{DoxyItemize}
