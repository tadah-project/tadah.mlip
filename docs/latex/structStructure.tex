\doxysubsection{Detailed Description}
Container for a collection of \mbox{\hyperlink{structAtom}{Atom(s)}}.

Holds list of \mbox{\hyperlink{structAtom}{Atom(s)}}, cell dimensions, system energy and stress tensor.

Pass this object to \mbox{\hyperlink{classNNFinder}{N\+N\+Finder}} to build a list of nearest neighbour positions for every \mbox{\hyperlink{structAtom}{Atom}} in the list.

Usage example\+: \begin{DoxyVerb}# Default constructor creates an empty Structure object.
# All attributes are left uninitialised
Structure st;
\end{DoxyVerb}


Usage example\+: \begin{DoxyVerb}# Print object summary with streams:
std::cout << st;

# Print 2nd atom data
std::cout << st(2)

# Print stress tensor
std::cout << st.stress
\end{DoxyVerb}
