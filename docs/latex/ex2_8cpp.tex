\doxysubsection{Detailed Description}
This example shows how to predict with a trained model. Example model is provided in a {\ttfamily pot.\+tadah} file.

To compile with {\ttfamily g++} and run\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{\$ g++ -\/O3 ex2.cpp -\/o ex2.out -\/ltadah -\/fopenmp}
\DoxyCodeLine{\$ ./ex2.out}
\end{DoxyCode}


Ta-\/dah! models and descriptors are selected at compile time but all model parameters are provided in the {\ttfamily pot.\+tadah} file. Model, cutoff and descriptors in the {\ttfamily \mbox{\hyperlink{ex2_8cpp}{ex2.\+cpp}}} file must match those in the {\ttfamily pot.\+tadah} file. See code comment bellow for more detail.
