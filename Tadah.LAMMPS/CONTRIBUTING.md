# Contributing

The full contributor guide for the Tadah! project lives in the
umbrella repository:

<https://github.com/tadah-project/tadah.mlip/blob/v1-dev/CONTRIBUTING.md>

For bug reports and feature requests on this module, please use the
issue tracker of this project:
<https://github.com/tadah-project/tadah.lammps/issues>. Cross-cutting
changes (work that touches more than one Tadah! module) should be
discussed on the umbrella project first.
