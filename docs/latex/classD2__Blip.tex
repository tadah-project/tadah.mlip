\doxysubsection{Detailed Description}
Blip two-\/body descriptor. 

\[ V_i^{\eta,r_s} =\sum_{j \neq i} B(\eta(r_{ij}-r_s))f_c(r_{ij}) \]

where $ f_c $ is a cutoff function and $ B $ is a blip basis function centered at $r_s$ of width $4/\eta$.

\mbox{\hyperlink{classConfig_CGRID2B}{C\+G\+R\+I\+D2B}} parameters control position $ r_s $ of blip centres.

\mbox{\hyperlink{classConfig_SGRID2B}{S\+G\+R\+I\+D2B}} parameters control width $ \eta $ of blips.

Blip basis function is built out of 3rd degree polynomials in the four intervals \mbox{[}-\/2,-\/1\mbox{]}, \mbox{[}-\/1,0\mbox{]}, \mbox{[}0,1\mbox{]}, \mbox{[}1,2\mbox{]} and is defined as\+:

\[ \begin{equation} B(r) = \begin{cases} 1-\frac{3}{2}r^2+\frac{3}{4}|r|^3 & \text{if} \qquad 0<|r|<1\\ \frac{1}{4}(2-|r|)^3 & \text{if} \qquad 1<|r|<2\\ 0 & \text{if} \qquad |r|>2 \end{cases} \end{equation} \]

More details about the blip basis functions can be found in the following paper\+:

Hernández, E., Gillan, M., Goringe, C. (1997). \mbox{\hyperlink{classBasis}{Basis}} functions for linear-\/scaling first-\/principles calculations. {\itshape Physical Review B -\/ Condensed Matter and Materials Physics}, {\itshape 55}(20), 13485–13493. \href{https://doi.org/10.1103/PhysRevB.55.13485}{\texttt{ https\+://doi.\+org/10.\+1103/\+Phys\+Rev\+B.\+55.\+13485}}
