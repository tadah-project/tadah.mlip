\doxysubsection{Detailed Description}
Base class for all models.

All models {\bfseries{must}} inherit this class and implement all methods.

Note that training is meant to be done by a constructor hence there is no training methods to implement.

{\footnotesize\ttfamily virtual double Model\+::epredict (\begin{DoxyParamCaption}\item[{const aed\+\_\+type \&}]{aed }\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [pure virtual]}}



Predict local energy of an atom or bond energy. 

The result depends on how aed is computed.

If it is computed between a pair of atoms than the result is a bond energy.

If aed contains sum over all nearest neighbours than the result is a local atomic energy $ E_i $.
