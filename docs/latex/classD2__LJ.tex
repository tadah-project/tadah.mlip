\doxysubsection{Detailed Description}
Standard Lennard -\/ Jones descriptor. 

\[ V_i = \sum_{j \neq i} 4 \epsilon \Bigg(\Big(\frac{\sigma}{r_{ij}}\Big)^{12} - \Big(\frac{\sigma}{r_{ij}}\Big)^6\Bigg) \]

or equivalently\+:

\[ V_i = \sum_{j \neq i} \frac{C_{12}}{r_{ij}^{12}} - \frac{C_6}{r_{ij}^6} \]

No cutoff function is used.

Note that machined learned coefficients $C_6$ and $C_{12}$ corresponds to $\sigma$ and $\epsilon$ through the following relation\+:

\[ \sigma = \Big(\frac{C_{12}}{C_6}\Big)^{1/6} \] \[ \epsilon = \frac{1}{4} \frac{C_6^2}{C_{12}} \]

The machine learned $\sigma$ and $\epsilon$ only make sense (say to compare with the literature ones) when \mbox{\hyperlink{classConfig_BIAS}{B\+I\+AS}} false and \mbox{\hyperlink{classConfig_NORM}{N\+O\+RM}} false. It is ok thought to set them to true it\textquotesingle{}s just that numerical values are different.
