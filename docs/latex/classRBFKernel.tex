\doxysubsection{Detailed Description}

Defined for two vectors {\bfseries{x}} and {\bfseries{y}}\+:

\[ K(\mathbf{x}, \mathbf{y}) = \exp\Big( -\frac{||\mathbf{x}-\mathbf{y}||^2} {2\sigma^2} \Big) \]
