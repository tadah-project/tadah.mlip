Standard Lennard - Jones descriptor

\[ V(r) = 4 \epsilon ((\frac{\sigma}{r})^{12} - (\frac{\sigma}{r})^6) \]

or equivalently:

\[ V(r) = \frac{C_{12}}{r^{12}} - \frac{C_6}{r^6} \]

No cutoff function is used.

Note that machined learned coefficients \(C_6\) and \(C_{12}\) corresponds to \(\sigma\) and \(\epsilon\) with the following relation:

\[ \sigma = (\frac{C_{12}}{C_6})^{1/6} \]

\[ \epsilon = \frac{1}{4} \frac{C_6^2}{C_{12}} \]

The machine learned \(\sigma\) and \(\epsilon\) only make sense (say to compare with the literature ones) when BIAS false and NORM false. It is ok thought to set them to true it's just that numerical values are different.
