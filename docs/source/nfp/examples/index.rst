.. _nfp_examples:

Examples
========

Each example applies one modelling or search decision to the
:ref:`Ta data <nfp_ta_data>` and explains the values it chooses. An example
builds on the units of the :ref:`tutorial <nfp_tutorial>` that it names and
needs a :ref:`Nested Fitting build <installation_nfp>`. The
:download:`files archive <../nfp-files.zip>` of the tutorial holds the files
of every example.
