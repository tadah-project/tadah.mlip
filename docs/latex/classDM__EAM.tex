\doxysubsection{Detailed Description}
many-\/body part for the Embedded \mbox{\hyperlink{structAtom}{Atom}} Method descriptor. 

\[ V_i = F\Bigg(\sum_{j \neq i} \rho(r_{ij}) \Bigg) \]

This descriptor will load tabulated values for the density $ \rho $ and embedded energy $ F $ from the provided \mbox{\hyperlink{classConfig_SETFL}{S\+E\+T\+FL}} file.

This descriptor is usually used together with the two-\/body descriptor \mbox{\hyperlink{classD2__EAM}{D2\+\_\+\+E\+AM}} although this is not required and user can mix it with any other descriptors or use it on its own.

This descriptor will enforce cutoff distance as specified in a \mbox{\hyperlink{classConfig_SETFL}{S\+E\+T\+FL}} file. Set \mbox{\hyperlink{classConfig_RCUTMB}{R\+C\+U\+T\+MB}} to the same value to suppress the warning message.

Required \mbox{\hyperlink{classConfig}{Config}} keys\+: \mbox{\hyperlink{classConfig_INITMB}{I\+N\+I\+T\+MB}} \mbox{\hyperlink{classConfig_SETFL}{S\+E\+T\+FL}}
