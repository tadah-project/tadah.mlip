\doxysubsection{Detailed Description}
\subsubsection*{template$<$class BF = Func\+\_\+\+Base\&$>$\newline
class M\+\_\+\+B\+L\+R$<$ B\+F $>$}

Bayesian Linear Regression

Model supported training modes\+:


\begin{DoxyItemize}
\item L\+I\+N\+E\+AR\+: Ordinary Least Squares or Ridge Regression (Regularised Least Squares)
\item N\+O\+N\+L\+I\+N\+E\+AR\+: Linear in parameters but nonlinear in an input space. Each row of a matrix $\Phi$ is a vector-\/valued function of the original input descriptor $ \mathbf{\phi(x)}^T $ e.\+g. \mbox{\hyperlink{structBF__Polynomial2}{B\+F\+\_\+\+Polynomial2}}\+: (1, x\+\_\+1, x\+\_\+2) -\/$>$ (1, x\+\_\+1, x\+\_\+2, x\+\_\+1x\+\_\+2, x\+\_\+1$^\wedge$2, x\+\_\+2$^\wedge$2)
\end{DoxyItemize}

\mbox{\hyperlink{classBasis}{Basis}} functions are selected at random. Number of basis functions is controled by \mbox{\hyperlink{classConfig_SBASIS}{S\+B\+A\+S\+IS}} key in a \mbox{\hyperlink{classConfig}{Config}} file.

{\bfseries{Prediction}}\+:

\[ y(\mathbf{x}, \mathbf{w}) = \sum_{j=0}^{M-1} w_j \phi_j(\mathbf(x)) \]

where M is a number of parameters, {\bfseries{w}} are machine learned weights and {\bfseries{x}} is a vector of input variables.

{\bfseries{Training}}\+:

\[ \mathbf{w} = (\lambda \mathbf{I} + \mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y} \]

for $\lambda=0$ this reduces to Ordinary Last Squares (O\+LS) aka Linear Least Squares with the normal equation\+:

\[ \mathbf{w} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y} \]

This model is always a linear function of its parameters $w_i$.

When used with linear basis function $\phi$ (here \mbox{\hyperlink{structBF__Linear}{B\+F\+\_\+\+Linear}}) it is also linear wrt to the input variables (here descriptors).

When nonlinear basis function $\phi$ is used the function $y(\mathbf{x}, \mathbf{w})$ becomes nonlinear wrt to {\bfseries{x}} but still linear wrt to {\bfseries{w}}.

{\bfseries{Optional \mbox{\hyperlink{classConfig}{Config}} keys}}\+:


\begin{DoxyItemize}
\item \mbox{\hyperlink{classConfig_LAMBDA}{L\+A\+M\+B\+DA}} = 0 -\/$>$ use O\+LS
\item \mbox{\hyperlink{classConfig_LAMBDA}{L\+A\+M\+B\+DA}} $>$ 0 -\/$>$ manually set to given value
\item \mbox{\hyperlink{classConfig_LAMBDA}{L\+A\+M\+B\+DA}} = -\/1 -\/$>$ use evidence approximation to find $\lambda$
\item \mbox{\hyperlink{classConfig_SBASIS}{S\+B\+A\+S\+IS}} N -\/$>$ Use N basis functions when nonlinear BF is used
\end{DoxyItemize}
