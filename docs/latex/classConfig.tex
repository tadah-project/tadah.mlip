\doxysubsection{Detailed Description}
A dictionary for key -\/ value pairs. 

This dictionary object must be used in the workflow to configure other objects in the training process.

A \mbox{\hyperlink{classConfig}{Config}} object stores information such as\+:
\begin{DoxyItemize}
\item cutoff distances
\item descriptor parameters
\item paths to training database files
\item and many more...
\end{DoxyItemize}

Every object using a \mbox{\hyperlink{classConfig}{Config}} class specifies a list of required and optional K\+EY -\/ V\+A\+L\+UE pairs.

The config keys and values are case insensitive.
