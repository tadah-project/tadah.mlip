API Quick Start
===============

This page points to the shortest way into the C++ library. It needs the installed libraries and their include and link flags (:ref:`compiling_and_linking`).

:ref:`Example 1 <ex1>` trains a potential from a training configuration and predicts with it. :ref:`Example 2 <ex2>` predicts with an existing potential. Both examples list their source files in full.

The API Reference describes the main classes of the examples: :doc:`Context <API/config>`, :doc:`StructureDB <API/structure_db>`, :doc:`NNFinder <API/nn_finder>`, :doc:`DescriptorsCalc <API/descriptors_calc>` and the base classes of the :doc:`models <API/models>`, :doc:`descriptors <API/descriptors>` and :doc:`cutoffs <API/cutoffs>`.
