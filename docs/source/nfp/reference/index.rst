optimiser and every :hpo:key:`OPTIMIZER.PARAM` key, as ``tadah hpo`` reads
them. Each entry gives the syntax, the values, the default, where the key
may appear and an example. The :ref:`nested_fitting` page introduces nested
fitting and its input files.
