\doxysubsection{Detailed Description}
Nearest Neighbour Finder

Construct a full nearest neighbour list for every atom in a structure.

The lists are ststored with a \mbox{\hyperlink{structStructure}{Structure}} object provided.

The cutoff used is max(\mbox{\hyperlink{classConfig_RCUT2B}{R\+C\+U\+T2B}},\mbox{\hyperlink{classConfig_RCUT3B}{R\+C\+U\+T3B}},\mbox{\hyperlink{classConfig_RCUTMB}{R\+C\+U\+T\+MB}})
